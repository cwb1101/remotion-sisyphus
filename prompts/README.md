# Remotion 横屏知识短视频 · 四步提示词（优化版）

按顺序在同一个对话里发送。第 1 步里的【全片硬性规范】是后面所有步骤的验收标准，第 3、4 步会再次点名，防止写代码时被遗忘。

本版新增的要求：

- 字幕放在画面下方，右侧不放任何字
- 只做横屏，不做竖屏，也不做竖屏式构图
- 字幕正文用白色，重点词用强调色
- 音效音量偏小，并去掉底噪、嘶嘶声、咔哒声和爆音
- 画风不只有点和线，适当加入代码绘制的简约人物

---

## 第 1 步：出方案

```
我要用 Remotion 做一条抖音横屏知识短视频：画面全部用代码做成动画，不用实拍素材，也不用图库素材。

【主题】：________
【时长】：约 __ 分钟
【形式】：1920×1080 横屏（16:9），30fps，无口播，字幕就是全部文字，配合成音效。不做竖屏，也不要在横屏画布里按竖屏的思路排版，画面左右两侧都要用起来。

【全片硬性规范】（方案、字幕稿和代码都要遵守，后面每一步我都按这几条验收）
1. 字幕位置：主字幕放在画面下方、水平居中。字幕块宽度不超过 1200px（x 360–1560），底边离画面底部至少 80px，每屏最多两行
2. 右侧禁字区：x ≥ 1560 的整条竖带不放任何字幕、关键词或标注文字，右上角留给水印。右侧可以放画面主体（物件、人物、光），只是不能放字
3. 字幕配色：正文一律用白色 #FFFFFF，重点关键词和数字用强调色区分。每屏最多 2 处高亮，全片最多两种强调色，同一类含义始终用同一种颜色。字幕下方加一层淡淡的暗色渐变或文字阴影，保证白字在亮背景上也看得清
4. 音效：音效只是点缀，不能抢戏，整体音量偏小。关键句的音效可以最响，但也不能刺耳。所有合成音效都不能有底噪、嘶嘶声、电流声、咔哒声或爆音
5. 画风：不要只有点和线。画面可以用形状、光、文字、粒子和线条，讲到"人"的段落再适当加入代码绘制的简约人物（几何剪影或扁平人形，不画五官细节）。人物要有动作（走、推、停、抬头、转身），并且和贯穿物件互动，不能只当装饰

先不要写代码，也不要写完整稿，只给我一份方案：
1. 选题一句话：观众看完带走的是哪一个观点
2. 主线问题：一个能让观众带着看完的问题
3. 开头三个备选，标出你推荐哪个。每个都写出前 5 秒的字幕（用【】标出高亮词）和画面动作
4. 全片结构：每节用一句话说明讲什么，估一下时长，并标出哪几节有人物出场、人物在做什么
5. 视觉方向两到三个，每个都写清楚：
   - 底色、字幕白、重点词强调色，全部用六位色值
   - 贯穿全片的一个物件或形状
   - 人物的画法（剪影、线描或扁平几何）和配色
   只写代码做得出来的画面（形状、光、文字、粒子、线条、几何人物）
6. 需要我核实的事实，以及可能有平台风险的地方

等我选定开头和视觉方向，你再写完整字幕稿；字幕定稿之后才开始写 Remotion 代码。
```

## 第 2 步：写字幕稿

```
我选：开头一 + 视觉方向 A。

另外几处先改：
- 开头不要黑场，第一帧就出第一句字幕。沙粒声叠在字幕下面，音量要轻，听起来是细细的沙沙声，不能是刺耳的白噪声
- 18,250 这屏要让观众看懂是怎么算的，比如"如果你 30 岁，还剩大约 18,250 天"
- 方向 A 的颜色写全：底色、字幕白、强调色（不超过两种）、人物配色，全部用完整的六位色值

请写完整字幕稿，格式用表格，一行一屏：
| 时间码 | 字幕 | 画面动作 | 人物 | 音效（类型 / 弱·中·强） |

要求：
1. 字幕就是全部文字，没有口播。按每秒约 5 字估时长，读不完的就拆成两屏
2. 每屏一句短句。重点词用【】标出来，后面用强调色高亮，其余字幕一律白色；每屏【】不超过 2 处
3. 字幕位置固定在画面下方居中，右侧禁字区不放字。"砸下来"的大字放在画面中部或偏左，不能进右侧禁字区，也不能压住底部字幕
4. 画面全程在动，同一个画面最多挂两屏字幕；贯穿物件要跟着论点一起变化
5. 人物适当出场：讲到人的处境、选择或对比时才用，写清楚人物的动作，以及他和贯穿物件的关系；不需要人物的屏，"人物"一栏留空
6. 音效分弱、中、强三档。"强"只留给关键句，全片控制在 5 处左右，其余以弱、中为主
7. 所有画面都要能用 Remotion 代码做出来，不用素材
8. 核实没通过的事实不要写进去
9. 最后附上：总字数、总时长、人物出场的屏号列表，再列出你最没把握的三句

先只出文字稿，不写代码。
```

## 第 3 步：做 30 秒预览

```
用 Remotion 搭项目。先只做前 30 秒左右（开头加第一节）当预览，不做完整片。第 1 步的【全片硬性规范】全部生效。

1. 字幕定稿存成一个数据文件，每屏写清楚：开始帧、结束帧、文字、重点词、重点词颜色、音效档位。画面和音效的时间都从这个文件里取，以后改字幕只改这一个文件
2. 组件拆分：
   - 每节写成一个组件
   - 贯穿全片的物件单独做成一个组件，各节复用
   - 人物单独做成一个组件（SVG 几何人形），用参数控制姿态、朝向、大小和颜色，动作靠关节角度插值来做，各节复用
   - 字幕单独做成一个组件，位置固定在底部，不跟着镜头缩放、平移
3. 不要做成 PPT 翻页：
   - 整片当成一个连续镜头来拍，场景之间用推近、拉远、平移过渡，不要原地换内容
   - 每节换一次场景，背景、光线、景别至少变一样
   - 贯穿物件是主角，要长大、变形、填满画面，不能一直是背景里的小点
   - 主题词和关键句要有大动作：大字砸到画面中部或偏左，不进右侧禁字区，配全屏级别的画面；音效用"强"档，但不能刺耳
   - 画面一直在动，不能出现超过几秒的静止画面
4. 音效用代码合成成 wav 文件（48kHz / 16bit），按时间轴放进去，不用任何音频素材。音量和噪音要求：
   - 三档音量：弱（环境、沙粒）峰值约 -24 dBFS；中（转场、出字）约 -16 dBFS；强（关键句）约 -8 dBFS。任何时刻峰值都不超过 -6 dBFS
   - 全片整体响度约 -20 LUFS，宁可偏小，不要偏大
   - 噪声类音效（沙粒、风、沙沙声）必须先滤波：切掉 100Hz 以下的轰鸣和 6kHz 以上的嘶声，再压低电平。不要整段铺白噪声当底
   - 每个音效首尾加 10–20ms 淡入淡出，避免咔哒声；多个音效叠加时在总线上加限幅，不能削波
   - 没有音效的地方必须是干净的静音，不能留底噪
5. 字幕排版：
   - 字体用思源黑体或思源宋体，主字幕不小于 64px
   - 放在画面下方居中，字幕块 x 360–1560，底边离画面底部至少 80px，最多两行
   - 正文用白色 #FFFFFF，重点词用方向 A 的强调色
   - 底部加暗色渐变带或文字阴影，保证可读性
6. 渲染出 mp4 以后自己先检查一遍，修好再给我：
   - 画面：每 2 秒抽一帧，看字有没有被挡住、有没有出画、有没有还没读完就切走的屏；字幕是不是都在底部区域，右侧禁字区里有没有字，高亮颜色对不对，人物有没有穿模或被裁切
   - 音频：用 ffmpeg 的 ebur128 和 astats 测整体响度、最大峰值和削波样本数，把峰值超过 -6 dBFS 的时间点列出来修掉；把噪声类音效单独放大听一遍，确认没有嘶嘶声和咔哒声
7. 交给我四样东西：预览 mp4 的路径、渲染命令、音频实测数据（整体响度、最大峰值、削波样本数）、你自己发现并修掉的问题

我看过预览、确认风格之后，再做完整片。
```

## 第 4 步：做完整片

```
预览风格定了，按这个风格做完整片。第 1 步的【全片硬性规范】继续全部生效：字幕在底部、右侧禁字区不放字、字幕白色加强调色、音量偏小且无噪音、适当加入人物。

1. 按字幕定稿把剩下的各节全部做完，镜头、场景切换、贯穿物件和人物的变化都延续预览的做法。前面预览部分已经改好的地方不要动
2. 每节之间要连续过渡，不要黑场切换；每节至少换一次景别或背景
3. 主线问题在结尾回收：开头抛出的问题，片尾要给出答案，画面上要和开头呼应（同一个物件、同一个人物，或者同一个构图）
4. 音效按时间轴补全，沿用预览的三档音量和降噪做法：
   - 全片整体响度约 -20 LUFS，任何时刻峰值不超过 -6 dBFS，削波样本数为 0
   - 关键句的音效最响，但仍在上限以内
   - 不能出现意外的静音，也不能出现底噪、嘶嘶声、咔哒声
5. 分段渲染，渲完合成一个完整 mp4；合成时检查各段接缝处有没有爆音或断音
6. 交片前自查：
   - 每 2 秒抽一帧检查：字有没有被挡、有没有出画、有没有还没读完就切走；字幕是否都在底部区域，右侧禁字区和水印区里有没有字
   - 找出画面静止超过几秒的段落，补上动作
   - 音频：用 ffmpeg 的 ebur128、astats、silencedetect 测一遍，列出整体响度、最大峰值、削波样本数、所有静音段，以及超过 -6 dBFS 的时间点并修掉；噪声类音效放大再听一遍
7. 交给我：成片路径、总时长、音频实测数据、每节画面怎么接到下一节（每节一两句话）、自查时发现并修掉的问题
8. 画面右上角固定水印文字【肆号静匣Logos】，文字外侧包一圈细空心方框。水印和方框放在镜头运动之外，全程固定位置，不跟着镜头缩放变形。字号约 22px，线宽 1px，透明度约 35%，不干扰主体动画。字幕和任何动画文字都不要排到这个区域
```
