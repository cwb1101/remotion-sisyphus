# 抖音横屏知识短视频 · Remotion 全流程提示词

用法：按 0 → 1 → 2 → 3 → 4 的顺序在同一个窗口里发送。换新窗口继续时，先发「0 声线锁定」，再发要继续的那一段。

---

## 0 · 声线锁定（每个新窗口都先发这一段）

```
【配音声线锁定｜肆号静匣Logos 专用男声，所有窗口通用，不许替换】
声线：成熟、低沉、略带沙哑的男声，语气克制，像深夜讲故事。

- 引擎：sherpa-onnx 离线 TTS + Kokoro v1.1-zh 模型（kokoro-multi-lang-v1_1），全部本地运行，不调用任何在线配音服务
- 模型：https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_1.tar.bz2
- 说话人 sid=84（试听编号 D），语速 speed=0.92
- 后期处理（ffmpeg，参数一个都不改）：
  rubberband=pitch=0.94:formant=preserved,highpass=f=60,lowshelf=g=3:f=180,equalizer=f=350:t=q:w=1:g=-2,equalizer=f=2800:t=q:w=1.5:g=1.5,volume=4dB,asoftclip=type=atan:threshold=0.7,acompressor=threshold=-18dB:ratio=3:attack=10:release=120,lowpass=f=11000,loudnorm=I=-16:TP=-3:LRA=7,aresample=48000
- 输出：48kHz 单声道 wav，响度 -16 LUFS，真峰值不高于 -3dB
- 现成脚本在 GitHub 仓库 cwb1101/remotion-sisyphus 的 voice/ 目录：先 bash voice/setup.sh，再 python3 voice/tts.py --json <字幕数据文件> --outdir public/vo；脚本会生成每屏一个 wav 和 manifest.json（每屏配音秒数）。新项目里没有这个目录就从该仓库复制过来，不要自己重写参数
- 朗读规则：字幕里的【】不读；空格读成短停顿；数字、英文、多音字按字幕稿「配音提示」一栏的写法读
- 验收：合成第一屏后报告中位基频（应在 105–118Hz）和语音识别回转的文字；对不上就停下检查参数
- 拿不到模型、或 ffmpeg 没有 rubberband 滤镜：停下来告诉我缺什么，不要换别的声音，也不要改用在线 TTS
```

## 1 · 出方案

```
我要用 Remotion 做一条抖音横屏知识短视频：画面全部用代码做成动画，不用实拍素材，也不用图库素材。

【主题】：
【时长】：约 150 秒
【形式】：1920×1080 横屏，30fps；男声配音（用「声线锁定」里的固定声线）+ 与配音逐字一致的字幕 + 合成音效
【语速】：锁定声线实测每秒约 3.4 字，150 秒约 450–500 字配音

先不要写代码，也不要写完整稿，只给我一份方案：
1. 选题一句话：观众看完带走的是哪一个观点
2. 主线问题：一个能让观众带着看完的问题
3. 开头三个备选，标出你推荐哪个，每个都写出前 5 秒的配音字幕和画面动作（5 秒约 17 字，开口第一句就要抛出钩子）
4. 全片结构：每节写一句话说明讲什么，再按字数估时长；每节再起一个 2–6 字的小标题，后面放在画面左侧做主题标注
5. 画风：先联网搜索当下主流的爆款「vibe 知识大赏」画风，挑三款给我选。每款写：风格名和代表作品、为什么火、底色和强调色、贯穿全片的一个物件或形状、人物怎么画、想象力体现在哪，以及它和低沉沙哑男声的气质是否搭。只写代码做得出来的画面（形状、光、文字、粒子、线条，以及用 SVG 画的扁平人物、剪影、简笔小人）；不要只有点和线，适当的地方加入人物来演绎情节，画面多层次、多元素、多用视觉隐喻
6. 需要我核实的事实、可能有平台风险的地方，以及配音容易读错的词（多音字、数字、年份、外文人名）
```

## 2 · 写字幕稿（= 配音稿）

```
我选：推荐组合

请写完整字幕稿。字幕就是配音文本，两者逐字一致。格式用表格，一行一屏：
| 时间码 | 字幕 | 配音提示 | 画面动作 | 音效 |

要求：
1. 按每秒约 3.4 字估时长（锁定声线的实测语速），每屏之间留约 0.3 秒气口；一屏读不完就拆成两屏，单屏最好 2–5 秒
2. 每屏一句短句，最多两行；字幕里不要任何标点，需要停顿用空格代替（配音会把空格读成短停顿）；重点词用【】标出来，后面做成高亮（【】只是标记，不上屏也不读）
3. 「配音提示」一栏平时留空；遇到多音字、数字、年份、英文、外文人名时，写出实际要读的汉字写法（例如 2000 年写成 两千年），关键句写一个语气提示（放慢、压低、停半拍）
4. 写成能听的句子：口语、短句、少用书面连接词；同一屏里不要连着出现三个以上的四字词，听起来会像念稿
5. 画面全程在动，同一个画面最多挂两屏字幕；贯穿物件要跟着论点一起变化
6. 画面想象力丰富一点：每屏写清前景、中景、背景各有什么元素；适当的地方让人物出场演绎（做动作、变表情、和贯穿物件互动），不要全片只有点和线；关键画面动作卡在配音的重点词上
7. 音效要合理，和画面动作对得上，并且给人声让路：以柔和的低频冲击、轻点击、气流声、柔和的上扬音为主；有配音时音效轻，重音效放在配音的停顿处或句尾，不和人声抢；不要刺耳的高频、尖锐的蜂鸣，也不要长时间的噪音铺底；关键句的音效可以重，但不能炸耳
8. 所有画面都要能用 Remotion 代码做出来，不用素材
9. 核实没通过的事实不要写进去
10. 最后附：总字数、按 3.4 字每秒估的配音总时长、配音提示一栏用到的词清单，再列出你最没把握的三句
```

## 3 · 搭项目 + 30 秒预览

```
用 Remotion 搭项目。先只做前 30 秒左右（开头加第一节）当预览，不做完整片。配音按「声线锁定」执行。

1. 字幕定稿存成一个数据文件，每屏写清楚：id、文字、重点词、配音提示（voiceText，可选）。每节的小标题也写在这个文件里
   - 先用 voice/tts.py 按这个文件合成每屏配音，得到 manifest.json
   - 每屏的开始帧、结束帧由脚本根据实际配音时长算出来：开始帧 = 上一屏结束帧，结束帧 = 开始帧 + 配音时长 + 约 0.3 秒气口；不要手填帧数
   - 画面和音效的时间都从这个文件和 manifest 里取；以后改字幕只改这一个文件，然后重跑配音脚本
2. 每节写成一个组件；贯穿全片的物件单独做成一个组件，各节复用；人物也单独做成可复用组件（SVG 绘制，能换动作和表情；配音时人物可以有轻微的呼吸或点头动作，但不做对口型）
3. 不要做成 PPT 翻页：
   - 整片当成一个连续镜头来拍，用推近、拉远、平移在场景之间过渡，不要原地换内容
   - 每节换一次场景，背景、光线、景别至少变一样
   - 贯穿物件是主角，要长大、变形、填满画面，不能一直是背景里的小点
   - 主题词和关键句要有大动作：字要大、要砸下来，配全屏级别的画面和音效；砸下来的时刻对准配音读到重点词的那一帧
   - 画面一直在动，不能出现超过几秒的静止画面
   - 画面层次要丰富：前景、中景、背景都有元素在动，适当用人物演绎情节，不要只有点和线
4. 音频分两轨：
   - 配音轨：每屏 wav 按时间轴放进去，响度统一在 -16 LUFS
   - 音效轨：用代码合成成 wav 文件，按时间轴放进去，不用任何音频素材。音色要柔和：每个音效都加淡入淡出包络，避免咔哒声；少用高频和白噪声；有配音时音效比人声低约 10dB，配音停顿处才放重音效
   - 混音后整体峰值不高于 -3dB，不能刺耳
5. 字幕样式：
   - 字体用思源黑体或思源宋体，主字幕不小于 64px
   - 放在画面下方，距底边约 80–120px；横排，最多两行，不要竖排
   - 水平居中，单行宽度不超过 960px；画面右侧 1/4（x>1440）不出现任何字幕，右上角水印除外
   - 屏幕上不显示任何标点
   - 文字以白色为主，重点词只用画风里的一个强调色；不描边、不渐变、不加花哨特效，可以加一层很淡的阴影保证看清。简约就是高级
   - 字幕和配音同步：配音开口时字幕已经在屏上，配音读完后字幕至少再停 0.3 秒
6. 画面左上角固定一个主题标注：第一行是本期主题（一句话），第二行是当前小节的小标题，换节时小标题平滑切换。标注放在镜头运动之外，全程固定位置，不跟着镜头缩放；字号小、透明度适中，不抢主体，也不和字幕重叠
7. 渲染出 mp4 以后自己先检查一遍：
   - 每 2 秒抽一帧看：字有没有被挡住、有没有出画、有没有还没读完就切走的屏、右侧有没有出现字幕、有没有漏掉的标点
   - 配音：用语音识别把配音转回文字，逐屏和字幕对照，标出读错的字；检查字幕和配音有没有错位
   - 声音：有没有刺耳或爆音，人声有没有被音效盖住，有没有意外的静音
   修好再给我
8. 交给我四样东西：预览 mp4 的路径、配音生成命令、渲染命令、你自己发现并修掉的问题

我看过预览、确认风格和配音之后，再做完整片。
```

## 4 · 完整片

```
预览风格和配音定了，按这个风格做完整片。配音继续按「声线锁定」执行，参数不改。

1. 按字幕定稿把剩下的各节全部做完，镜头、场景切换、贯穿物件的变化、人物演绎、多层画面元素都延续预览的做法。前面预览部分已经改好的地方不要动
2. 每节之间要连续过渡，不要黑场切换；每节至少换一次景别或背景
3. 主线问题在结尾回收：开头抛出的问题，片尾要给出答案，配音和画面都要和开头呼应
4. 配音：剩下各屏用同一个脚本、同一组参数合成，全片人声响度统一在 -16 LUFS；不要重新合成预览部分已经确认的配音
5. 音效按时间轴补全；音效给人声让路，关键句的音效最响但放在配音停顿处；全片不能出现意外的静音；音色保持柔和，不要刺耳的高频和噪音
6. 分段渲染，渲完合成一个完整 mp4
7. 交片前自查：
   - 每 2 秒抽一帧检查：字有没有被挡、有没有出画、有没有还没读完就切走、右侧有没有字幕、有没有标点、字幕是否都在下方且不超过两行
   - 左上角主题标注的小标题是否随每节正确切换
   - 找出画面静止超过几秒的段落，补上动作
   - 配音：语音识别回转全片，逐屏和字幕对照；检查字幕和配音是否同步、各段之间声线和音量有没有跳变
   - 听一遍音频，标出静音段、爆音、刺耳的地方，以及人声被音效盖住的地方
8. 交给我：成片路径、总时长、每节画面怎么接到下一节（每节一两句话）、自查时发现并修掉的问题
9. 画面右上角固定水印文字【肆号静匣Logos】，文字外侧包一圈细空心方框。水印和方框放在镜头运动之外，全程固定位置，不跟着镜头缩放变形。字号约 22px，线宽 1px，透明度约 35%，不干扰主体动画。字幕和任何动画文字都不要排到这个区域
```
