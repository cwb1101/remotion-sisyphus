# BGM 分析

文件：`assets/music/bgm.mp3`（48kHz 立体声 192kbps）。脚本：`scripts/analyze_music.py`，完整数据：`assets/music/bgm.analysis.json`。

## 基本参数

| 项 | 值 |
|---|---|
| 曲长 | **44.64 s**（1339 帧）。注意：只有目标片长的约 1/3 |
| BPM | **168.22**（网格拟合；librosa 原始 167.9）。体感是半速 **84.1 BPM**，底鼓约每 0.713 s 一下 |
| 拍距 | 0.3567 s ≈ 10.7 帧 |
| 首拍 | 0.180 s；0.15 s 起直接满鼓，**没有前奏** |
| 4 拍小节 | 1.427 s，共 31 个 |
| 16 拍乐句 | 5.707 s：0.18 / 5.89 / 11.59 / 17.30 / 23.01 / 28.71 / 34.42 / 40.13 |
| 和声循环 | 每 8 拍一个和声块（2.853 s），按 a-b-c-c 排列，32 拍（11.41 s）循环一次 |
| 底鼓 | 54 个，大多落在偶数拍，离网格中位 21 ms，最大 49 ms（都不超过 1.5 帧）。卡重拍时用 JSON 里 `kicks[].frame` 的实测帧 |
| **drop** | **23.01 s**（第 64 拍）：break 之后低频回归 |
| 能量 | 全曲 RMS 几乎是平的（−15 到 −19 dB）；段落差别主要在低频有没有被抽掉，以及高频亮不亮 |

## 段落表（原曲时间）

| 段落 | 原曲时间 | 听感依据 | 适合放什么 |
|---|---|---|---|
| 前奏 | 0.00–0.18 | 没有独立前奏，一开始就满鼓 | 本身放不了内容。需要静一点的开头时，用低通滤波把 0.18–11.59 做成“闷住”的假前奏（示意） |
| 铺垫 | 0.18–11.59 | A 段律动，a-b-c-c 和声走两遍，质心约 1850 Hz，偏暗 | 钩子：演那个反常识的小现象，字幕少、节奏慢，一个和声块一句 |
| 蓄力 | 11.59–20.15 | 和声循环重来一次，17.3 s 起质心升到 2400 Hz，高频变亮 | 实证：一件接一件摆证据（年份、数字），每 2.85 s 一条 |
| break | 20.15–23.01 | 低频抽空约 4 dB，质心 3180 Hz（过门、镲） | 吸气：画面收住，只留一句问题或一个停顿，给 drop 蓄力 |
| **drop / 高潮** | **23.01**–40.13 | 低频回来，B 段比 A 段亮（hi-hat 更密，质心 2100–2450 Hz） | 主题词砸下来（大动作）、核心论点、最密集的画面变化 |
| 尾段 | 40.13–44.64 | 最后一个 c 块，**42.98 s 一记收尾重击**，44.2 s 后快速衰减，没有淡出 | 回扣开头、金句收尾；42.98 s 的重击可以给最后一个画面 |

## 长度问题与重编方案

> **现行做法**：`python scripts/bgm.py --seconds 147.4 --drop 23` 输出 `public/audio/bgm.wav` 和 `src/data/beatmap.json`
> （铺垫按原曲走，drop 在 22.87 s，高潮段 P4-P5-P6-P5 循环，尾段完整播出）。下面两套是第 1 步的备选，留作记录。

44.64 s 撑不满 150 s。每个 8 拍块的和声都能对上（a/b/c 块之间的相似度 ≥ 0.99），所以可以在块边界无缝拼接。

**方案 A（推荐）：按块重编成约 145 s，带两个 drop 和一个低通假前奏**

| 片中时间 | 帧 | 用原曲哪几块 | 作用 |
|---|---|---|---|
| 0.00–11.41 | 0–342 | 0-1-2-3 低通 | 假前奏，钩子 |
| 11.41–22.83 | 342–685 | 4-5-6-3 | 滤波打开，主线问题 |
| 22.83–34.24 | 685–1027 | 4-5-6-7 | 实证；31.39 起进入 break |
| **34.24** | **1027** | 8-9-10-11 | **drop 1：主题词** |
| 45.65–57.07 | 1370–1712 | 12-13-14-11 | 落到观众 |
| 57.07–68.48 | 1712–2054 | 0-1-2-3 | 落到观众 |
| 68.48–79.90 | 2054–2397 | 0-1-2-3 低通 | 机制（静段，呼吸） |
| 79.90–102.72 | 2397–3082 | 4-5-6-3、0-1-2-3 | 机制 |
| 102.72–114.14 | 3082–3424 | 4-5-6-7 | 推向答案；111.28 起进入 break |
| **114.14** | **3424** | 8-9-10-11 | **drop 2：金句** |
| 125.55–134.11 | 3766–4023 | 12-13-14 | 回扣开头 |
| 134.11 | 4023 | 收尾重击 | 最后一个画面 |
| 135.77–约 145 | 4073– | 0-1-2 低通淡出 | 片尾出处 |

**方案 B（不剪音乐）：原曲循环 3 遍**（循环体 0.18–42.98 s），drop 自然落在 23.01 / 65.81 / 108.61 s，130.2 s 结束，之后约 8 s 静音放出处。改动最少，但开头没有安静段，三个 drop 的位置也不能挪。
