## 二 选题

**观众带走的一个观点**：
依赖本身没有错 错的是只依赖一个人——把自己整杯倒给对方 只从对方那里喝水 爱不会变浓 只会更渴。

**反常识切入点**：
大家常说「太依赖了 就要学会独立」。研究给的方向几乎相反：
- 被伴侣稳稳接住依赖的人 反而更敢独自去闯（Feeney 2007 依赖悖论）
- 幸福感更高的人 不一定有一个什么都能说的人 而是不同的情绪找不同的人（Cheung 等 2015）
- 把所有需要都交给一个人 关系会缺氧（Finkel 等 2014 婚姻窒息模型 理论）

所以答案不是「少爱一点」，而是「多几个水源 先把自己的杯子装上」。

## 六 视觉方向

### 方向 1 鎏金暗场 · 金缮杯（**推荐**）
- **底色**：暖近黑 #15110C 中心略亮，四角压暗；前景漂着失焦的金色尘埃
- **强调色**：象牙白 #E8E3D9（字幕 杯身）；金 #DDBD74（重点词 轮廓光 金缮裂纹）；朱红 #D9583C（只给主角围巾和主角杯里的液体）
- **字幕**：思源宋体 Heavy 72px，逐字由模糊到清晰；重点词染金
- **人物画法**：实心暗色剪影 #0B0907，迎光一侧 2 px 金色轮廓光；头身比 1:7；关节骨架驱动（颈 肩 肘 腕 髋 膝 踝），四肢是两头粗细不同的胶囊形 有体积
- **主角识别**：一条朱红长围巾 尾巴随动作和呼吸摆动（弹簧模拟），远景两三个像素宽也认得出
- **贯穿物件**：一只白瓷杯
- **变化线**：满杯 → 倒空 → 举着空杯 → 两杯液体融成一股浊色 → 变成手机屏幕的光（第 4 节）→ 每次确认液面涨一点又更快跌回 → 裂纹 → 摔碎 → 一片片捡起 金色裂纹把它拼回 → 从几个水源各接一点 七分满 → 碰杯
- 金缮（金粉修补瓷器）正好用上这个画风的金色，「碎了重新捡起」有画面依据

### 方向 2 寓言 · 拆毛衣
- **底色**：暖白 #FFFAEB；墨色线条 #2E2A26
- **强调色**：金 #EEC672；红 #FC593F（主角毛衣 + 关键词）
- **人物画法**：扁平插画小人 圆头 两点眼 一弧嘴 衣服是色块；头身比 1:3.5；表情能演
- **主角识别**：一件红毛衣
- **贯穿物件**：一团从主角毛衣上拆下来的红毛线
- **变化线**：拆自己的袖子 给对方织围巾 → 毛衣越来越短 主角冷得发抖 只能贴着对方取暖 → 毛线把两人缠在一起（融合）→ 毛线变成手机充电线（第 4 节）→ 越拉越紧 对方被拖着走 → 84.94 线断 主角往后跌倒 → 捡起线头 先给自己织回袖子 再和几个朋友各牵一股 织成一张能躺的网 → 结尾两人各穿各的毛衣 共围一条松松的围巾
- 风险：毛线是线 要保证线始终是被人拿着的物件 不被读成「连线代表关系」

### 方向 3 夜曲 · 提灯
- **底色**：蓝黑 #0A0F1E → #141B33 渐变 细小星点（星点只做氛围）
- **强调色**：白 #F8F9F8 细宋字幕 字距大 整行淡入；金 #F8D893 灯光；玫红 #E84B75 只给主角的灯穗；冰蓝 #64E3F6 只用在极少的星光高光上 避免霓虹感
- **人物画法**：深蓝实心剪影 #1A2240 被手里的灯照亮半边；头身比 1:7
- **主角识别**：提灯上一束玫红灯穗
- **贯穿物件**：一盏纸灯笼
- **变化线**：把自己的火苗引到对方灯里 自己的灯灭了 只有站在对方身边才看得见 → 两团火并成一团（融合）→ 灯光变成黑暗卧室里唯一的手机光（第 4 节）→ 把灯凑得太近 火苗摇晃 → 84.94 灯笼掉落烧尽 全屏黑 → 划一根火柴 重新点亮自己的灯 远处出现几位提灯的朋友 → 两盏灯并排走远
