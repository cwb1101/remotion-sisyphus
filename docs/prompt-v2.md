# Remotion 知识短视频提示词 v2（按第一条片子的问题修订）

## 第一条片子的问题和原因

1. **音效不全**：字幕出现、大字落下、镜头推拉、场景转换大多没有声音。原因是提示词只要求"每屏一格音效"，没有规定哪些动作必须有声音，结果每屏只配了一个。
2. **音效偏轻**：档位按峰值算，短促音效峰值够了但听感很弱。而且主要能量落在 50–120Hz 的闷响上，手机外放几乎放不出来。
3. **不好听，像电流声**：为了凑 -20 LUFS，垫了一层 110/220Hz 的长时间正弦和弦。低频纯音一直响，手机上听就是"嗡"的电流声。全是单纯正弦，也没有质感、空间感和立体声。另外，AI 只能用仪器测，不能真的听，流程里应该先出声音小样给人试听。
4. **第一帧是黑的**：第 0 帧房间还没画出来，只有人站在暗底上。
5. **画面单调**：150 秒几乎都是同一个房间、同一种暗底、同一种机位，新内容只是往房间里加道具。延续画风被理解成了重复构图。
6. **人物太多**：51 屏里有 41 屏出现人物，讲概念、讲定义的地方也放了人。

## 第 1 步：方案

```
我要用 Remotion 做一条抖音横屏知识短视频：画面全部用代码做成动画，不用实拍素材，也不用图库素材。请把自己当成大师级剪辑师：画面有想象力，声音好听，节奏跟着文案走。

【主题】：
【时长】：约 150 秒
【形式】：1920×1080 横屏（16:9），30fps，无口播，字幕就是全部文字，配合成音效（可加代码合成的轻音乐垫底，见第 4 条）。不做竖屏，也不要在横屏画布里按竖屏的思路排版，画面左右两侧都要用起来。

【全片硬性规范】（方案、字幕稿和代码都要遵守，后面每一步我都按这几条验收）
1. 字幕位置：主字幕放在画面下方、水平居中。字幕块宽度不超过 1200px（x 360–1560），底边离画面底部至少 80px，每屏最多两行。
2. 右侧禁字区：x ≥ 1560 的整条竖带不放任何字幕、关键词或标注文字，右上角留给水印。右侧可以放画面主体（物件、人物、光），只是不能放字。
3. 字幕配色：正文一律用白色 #FFFFFF，重点关键词和数字用强调色区分。每屏最多 2 处高亮，全片最多两种强调色，同一类含义始终用同一种颜色。字幕下方加一层淡淡的暗色渐变或文字阴影，保证白字在亮背景上也看得清。
4. 声音：
   - 不能缺：以下动作都要有声音——每屏字幕出现（很轻的出字音）、舞台大字落下、镜头明显推拉或转场、贯穿物件变形、人物的关键动作（推、撞、落地、开门）、关键句。
   - 要好听：音色要有质感（合成的打击、木质或玻璃质的点音、带扫频的气流声、短混响、立体声宽度），全片统一在一个调性里，不同类型的音效音色要有区分。
   - 手机外放听得见：主要能量放在 200Hz–5kHz；低频闷响上面叠一层中频的"敲击感"。
   - 禁止：持续超过 1 秒的 150Hz 以下纯音长鸣（会被听成电流声、嗡声）；整段铺噪声；底噪、嘶嘶声、咔哒声、爆音。
   - 背景音乐（不要就删掉这条）：代码合成的轻音乐垫底，有和弦进行和轻节奏，不是单音长鸣，音量比音效低 6–10dB。不加音乐时，没有音效的地方保持干净静音，不许用长鸣垫底凑响度。
   - 音效只是点缀，不能抢戏；关键句的音效最响，但不刺耳。
5. 画风与想象力：
   - 不要只有点和线。可用形状、光与阴影、粒子、线条、文字排版动画、图表和数据可视化、几何人物。
   - 延续画风指配色、线条语言、贯穿物件保持一致，不是重复同一个画面。
   - 每节至少引入一个新的视觉元素或视觉隐喻，不能只是在同一个构图里加道具。同一构图（同机位、同主体布局）全片最多出现 2 次。
   - 画面要有前景、中景、背景三层，有光影变化，也有尺度变化（微观和宏观来回切）。
6. 人物跟着文案走：只有讲到人的处境、选择、动作或对比时才出场；讲概念、定义、数据、推理的段落用物件、文字和图形表达。全片有人物的屏不超过一半。人物用代码绘制的简约人形（几何剪影或扁平人形，不画五官细节），要有动作（走、推、停、抬头、转身），并且和贯穿物件互动，不能只当装饰。
7. 首帧和尾帧：第 0 帧必须是一张完整、好看的画面（主体和关键物件已经在画面上，可以直接当封面），不能黑屏、不能空场。最后一帧也不能是黑屏。

先不要写代码，也不要写完整稿，只给我一份方案：
1. 选题一句话：观众看完带走的是哪一个观点
2. 主线问题：一个能让观众带着看完的问题
3. 开头三个备选，标出你推荐哪个。每个都写出前 5 秒的字幕（用【】标出高亮词）、画面动作，以及第 0 帧的画面
4. 全片结构：每节用一句话说明讲什么，估一下时长；标出这一节的新视觉元素或视觉隐喻；标出哪几节有人物、人物在做什么、为什么这里需要人物
5. 视觉方向两到三个，每个都写清楚：
   - 底色、字幕白、重点词强调色，全部用六位色值
   - 贯穿全片的一个物件或形状，以及它在各节怎么变化（长大、变形、拆开、重组）
   - 人物的画法（剪影、线描或扁平几何）和配色
   - 声音方向：调性、主要音色、出字音和转场音是什么质感、要不要音乐
   只写代码做得出来的画面（形状、光、文字、粒子、线条、图表、几何人物）
6. 需要我核实的事实，以及可能有平台风险的地方

等我选定开头和视觉方向，你再写完整字幕稿；字幕定稿之后才开始写 Remotion 代码。
```

```
我选：（填你选的开头和视觉方向）
请写完整字幕稿，格式用表格，一行一屏：
| 时间码 | 字幕 | 画面动作 | 新元素 / 视觉隐喻 | 人物（不需要就留空） | 声音（出字音 / 转场 / 动作 / 关键句，标弱·中·强） |

要求：
1. 字幕就是全部文字，没有口播。按每秒约 5 字估时长，读不完的就拆成两屏。

6. 声音一栏每屏都要填：出字音每屏都有（弱）；转场、大字落下、物件变形、人物关键动作按画面填；"强"只留给关键句，全片 5 处左右。
7. 第 1 屏写清楚第 0 帧是什么画面（不能黑屏）。
8. 所有画面都要能用 Remotion 代码做出来，不用素材。
9. 核实没通过的事实不要写进去。
10. 最后附上：总字数、总时长、人物出场的屏号列表（及占比）、每节新视觉元素的清单，再列出你最没把握的三句。

先只出文字稿，不写代码。
```

## 第 3 步：预览

```
你没有把握的地方就按你推荐的来。用 Remotion 搭项目。先只做前 30 秒左右（开头加第一节）当预览，不做完整片。第 1 步的【全片硬性规范】全部生效。

1. 字幕定稿存成一个数据文件，每屏写清楚：开始帧、结束帧、文字、重点词、重点词颜色、音效列表（出字音、转场、动作、关键句各自的类型和档位）。画面和音效的时间都从这个文件里取，以后改字幕只改这一个文件。
2. 组件拆分：
   - 每节写成一个组件。
   - 贯穿全片的物件单独做成一个组件，各节复用。
   - 人物单独做成一个组件（SVG 几何人形），用参数控制姿态、朝向、大小和颜色，动作靠关节角度插值来做，各节复用。
   - 字幕单独做成一个组件，位置固定在底部，不跟着镜头缩放、平移；字幕出现要有设计过的入场动画，并配出字音。
3. 不要做成 PPT 翻页：
   - 整片当成一个连续镜头来拍，场景之间用推近、拉远、平移过渡，不要原地换内容。
   - 每节换一次场景，背景、光线、景别至少变一样，并引入新的视觉元素，不能只是在同一个房间里加道具。
   - 贯穿物件是主角，要长大、变形、填满画面，不能一直是背景里的小点。
   - 主题词和关键句要有大动作：大字砸到画面中部或偏左，不进右侧禁字区，配全屏级别的画面；音效用"强"档，但不能刺耳。
   - 画面一直在动，不能出现超过几秒的静止画面。
   - 第 0 帧就是一张完整的画面，不能黑屏。
4. 声音用代码合成成 wav 文件（48kHz / 16bit，立体声），按时间轴放进去，不用任何音频素材：
   - 先做"声音小样"：把每一类音效（出字音、转场、物件变形、人物动作、关键句、可选的音乐垫底）各导出一个单独的 wav，再出一版 30 秒预览音轨，交给我试听，我确认音色后再往下做。
   - 音色：用加法合成、FM、滤波扫频、短混响、立体声声像做出质感，全片统一调性；不要只用单个正弦波。
   - 三档听感：弱 = 能听见但不会特意注意，中 = 清楚，强 = 明显但不刺耳。按峰值：弱约 -20 dBFS、中约 -13 dBFS、强约 -7 dBFS，任何时刻峰值都不超过 -3 dBFS。
   - 全片整体响度约 -16 LUFS（手机外放听感合适，误差 ±1）。不许用长鸣垫底来凑响度。
   - 噪声类音效（沙粒、风、沙沙声）必须先滤波：切掉 100Hz 以下的轰鸣和 6kHz 以上的嘶声，再压低电平。不要整段铺白噪声当底。
   - 每个音效首尾加 10–20ms 淡入淡出，避免咔哒声；多个音效叠加时在总线上加限幅，不能削波。
   - 禁止持续超过 1 秒的 150Hz 以下纯音长鸣。
   - 不加音乐时，没有音效的地方必须是干净的静音，不能留底噪。
5. 字幕排版：
   - 字体用思源黑体或思源宋体，主字幕不小于 64px。
   - 放在画面下方居中，字幕块 x 360–1560，底边离画面底部至少 80px，最多两行。
   - 正文用白色 #FFFFFF，重点词用选定方向的强调色。
   - 底部加暗色渐变带或文字阴影，保证可读性。
6. 渲染出 mp4 以后自己先检查一遍，修好再给我：
   - 画面：
     - 第 0 帧和最后一帧单独截图。
     - 每 2 秒抽一帧，看字有没有被挡住、有没有出画、有没有还没读完就切走的屏；字幕是不是都在底部区域，右侧禁字区里有没有字，高亮颜色对不对，人物有没有穿模或被裁切。
     - 列出用到的视觉元素和构图，确认没有重复构图。
   - 声音：
     - 列一张"音效覆盖表"：每屏的字幕出现、大字、转场、物件变形、人物动作有没有对应的声音。
     - 用 ffmpeg 的 ebur128 和 astats 测整体响度、最大峰值和削波样本数，把峰值超过上限的时间点列出来修掉。
     - 模拟手机外放（高通 250Hz）再测一次响度，确认听得见。
     - 检查有没有超过 1 秒的 150Hz 以下长鸣。
     - 噪声类音效单独放大检查，确认没有嘶嘶声和咔哒声。
     - 你不能真正试听，要在报告里写明哪些是仪器测的、哪些需要我听。
7. 交给我五样东西：预览 mp4 的路径、渲染命令、音频实测数据（整体响度、手机模拟响度、最大峰值、削波样本数）、声音小样文件、你自己发现并修掉的问题。

我看过预览、听过小样、确认风格之后，再做完整片。
```

## 第 4 步：完整片

```
预览风格定了，按这个风格做完整片。第 1 步的【全片硬性规范】继续全部生效：字幕在底部、右侧禁字区不放字、字幕白色加强调色、声音好听且无噪音、人物跟着文案走、首帧不能黑。

1. 按字幕定稿把剩下的各节全部做完，镜头、场景切换、贯穿物件和人物的变化都延续预览的做法。前面预览部分已经改好的地方不要动。
2. 画面丰富度：
   - 每节都要有新的视觉元素或视觉隐喻，同一构图全片最多出现 2 次。
   - 后半段不能比前半段简单；关键句要有全屏级别的画面。
   - 人物只在文案讲到人的时候出场，全片有人物的屏不超过一半。
3. 每节之间要连续过渡，不要黑场切换；每节至少换一次景别或背景。
4. 主线问题在结尾回收：开头抛出的问题，片尾要给出答案，画面上要和开头呼应（同一个物件、同一个人物，或者同一个构图）。
5. 声音按时间轴补全，沿用预览确认过的音色、档位和降噪做法：
   - 每屏的出字音、大字、转场、物件变形、人物关键动作都有声音。
   - 全片整体响度约 -16 LUFS（±1），任何时刻峰值不超过 -3 dBFS，削波样本数为 0。
   - 关键句的音效最响，但仍在上限以内。
   - 不能出现意外的静音，也不能出现底噪、嘶嘶声、咔哒声、电流声（包括 150Hz 以下的长鸣）。
6. 分段渲染，渲完合成一个完整 mp4；合成时检查各段接缝处有没有爆音或断音、画面有没有跳帧。
7. 画面右上角固定水印文字【肆号静匣Logos】，文字外侧包一圈细空心方框。水印和方框放在镜头运动之外，全程固定位置，不跟着镜头缩放变形。字号约 22px，线宽 1px，透明度约 35%，不干扰主体动画。字幕和任何动画文字都不要排到这个区域。
8. 交片前自查：
   - 第 0 帧、最后一帧截图，确认不是黑屏。
   - 每 2 秒抽一帧检查：字有没有被挡、有没有出画、有没有还没读完就切走；字幕是否都在底部区域，右侧禁字区和水印区里有没有字。
   - 找出画面静止超过 2 秒的段落，补上动作。
   - 列出每节的视觉元素和构图，标出重复的地方；统计人物出场的屏数和占比。
   - 声音：
     - 给出音效覆盖表。
     - 用 ffmpeg 的 ebur128、astats、silencedetect 测一遍，列出整体响度、手机模拟响度、最大峰值、削波样本数、所有静音段，以及超过上限的时间点并修掉。
     - 检查 150Hz 以下长鸣。
     - 噪声类音效放大检查。
     - 写明哪些需要我亲自试听。
9. 交给我：成片路径、总时长、第 0 帧截图、音频实测数据、每节画面怎么接到下一节（每节一两句话，写出用了什么新元素）、人物出场统计、自查时发现并修掉的问题。
```

## 第 5 步：封面与简介

```
帮我设计一张 3:4 封面（1080×1440），并写一段视频简介：
- 封面用片中的贯穿物件和配色，标题用开头的主线问题，底部一句答案作钩子，右上角同款水印。主体放在中间，抖音裁切后也完整。
- 简介 5 行以内：第一行是主线问题，中间 2–3 行讲核心观点，最后一行留一个让人想评论的问题，结尾加 4–6 个话题标签。
```
