# 「当我发现我怀念的不是学校而是…」这类视频怎么做

这类 20 秒左右的 MC 怀旧卡点视频由两部分组成：

1. **素材**：MC 风格的动画短镜头，每个镜头 2~3 秒
2. **包装**：大字标题、对白、卡点转场、调色

画面观感主要来自素材（光影和角色动作），「丝滑」的感觉主要来自包装（转场卡在音乐拍子上）。下面分开讲。

---

## 一、结构拆解

| 时间 | 内容 | 画面 |
|---|---|---|
| 0 ~ 3.7s（8 拍） | 钩子：「当我发现我怀念 / 的**不是学校而是…**」 | 主角背书包走在街上，字在左上角 |
| 每段 ~2.8s（6 拍） × 5 | 「1. 课间的嬉戏打闹」+ 英文 + 两句对白 | 每段一个场景、一个小动作 |
| 结尾 | 揭晓答案（原片截图里没有，模板里先写成「而是那群陪我长大的人」） | 合照或远景 |

规律：

- **切点都在重拍上**。128 BPM 的歌一拍约 0.47 秒，每段 6 拍左右
- **标题在切点那一拍砸进来**，对白在后面第 1~3 拍各弹出一句，一左一右
- 中文大字下面都有一行英文衬线小字，看起来更有设计感，也方便海外平台

---

## 二、素材：MC 动画镜头怎么做

截图里能看到浅景深、暖色夕阳、体积光、角色有表情（闭眼笑、紫色眼睛）、动作带运动模糊，所以这是渲染出来的动画，不是游戏录屏。常见的三条路线：

### 路线 A：Mine-imator（最容易上手）
- 免费的 MC 动画软件，自带 MC 角色骨骼，导入皮肤就能 K 帧
- 可以导入 MC 地图（schematic / 存档区域）当场景
- 新版自带不错的光照、景深和运动模糊，出图接近截图效果
- 适合：第一次做、想快速出片

### 路线 B：Blender + MCprep（质量最高，原片很可能是这种）
- 用 **jmc2obj / Mineways** 把 MC 地图导出成 obj，或者用 MCprep 直接导入世界
- **MCprep** 插件提供玩家骨骼（含面部表情 rig），套上皮肤就能做动作
- Cycles 渲染，加太阳光 + 体积雾，相机开景深和运动模糊
- 适合：追求截图那种光影质感

### 路线 C：游戏内录制（Replay Mod + 光影）
- Java 版 + Iris / OptiFine + 光影包（Complementary、BSL、Rethinking Voxels 之类）
- Replay Mod 回放后用相机路径录制，场景很好看
- 缺点：角色动作只能靠真人演或 Emotecraft 动作模组，表情和精细动作做不出来

### 素材小技巧
- **场景**：直接下载现成的「日式校园」「街道」地图，不用自己搭
- **皮肤**：二次元风格皮肤（大眼睛、发型分层）是这类视频的味道
- **每个镜头只做一个动作**：追逐、搭肩、趴桌、投篮，2~3 秒足够
- **运镜**：缓慢推近、低角度仰拍、侧面跟拍。渲染时多留 0.5 秒头尾，方便剪辑时卡点
- **导出**：1080p，30 或 60 帧，mp4

## 三、包装：为什么转场这么丝滑

### 1. 卡点
- 先确定 BGM 的 BPM（剪映「自动踩点」或在线 BPM 检测都可以）
- 所有切点放在重拍上，对白出现时间放在后面的拍子上
- 每一拍画面轻微放大一下再回弹（「顿」一下），观众会觉得画面在跟着音乐动

### 2. 缩放模糊转场（核心）
切点前后各约 0.2 秒（6 帧）：

```
切点前 6 帧：旧画面加速放大（1.0 → 1.35）+ 模糊 + 径向拖影 + 变亮 + 抖动加剧
切点那一帧：闪一下白（不透明度 ~35%）
切点后 6 帧：新画面从放大+模糊的状态快速收回到正常（ease-out）
```

两个画面在切点处都是糊的，硬切就看不出来，加上卡在鼓点上，观感就是丝滑。剪映里对应的是「拉镜」「推近」「缩放模糊」「震动」这类转场，时长调到 0.3 秒左右。

### 3. 画面质感
- **边缘模糊**：画面中间清楚、四周模糊（截图四角都是糊的），营造回忆感
- **暖色调**：饱和度 +15%、对比 +5%、整体偏橙黄
- **暗角 + 颗粒**：轻微就行
- **手持抖动**：一直有很小的随机晃动，转场时加大

### 4. 字效
| 元素 | 字体 | 颜色 | 动画 |
|---|---|---|---|
| 序号标题 | 粗壮标题字（站酷庆科黄油体 / 优设标题黑一类） | 黄 `#FFE016`，强调词用红 `#FF3B3B` | 逐字从 2.4 倍砸进来，带回弹 |
| 英文小字 | 衬线粗体（Playfair Display 一类） | 白 | 标题落地后上浮淡入 |
| 对白 | 最粗黑体，带中文引号 “” | 白 | 弹出 + 轻微摇摆 |

所有字都有**黑色粗描边 + 下投影**，标题边缘还有一点做旧毛边，这样在任何背景上都清楚。

## 四、两种做法

### 做法 1：剪映（最快）
1. 导入 BGM，右键「踩点」→「踩节拍 I」
2. 按节拍点把素材切开、排好，每段 6 拍左右
3. 每个切点加「缩放模糊 / 拉镜」类转场，时长 0.3s
4. 全局加特效：「边缘模糊」「暖色胶片」「颗粒」
5. 文字：标题用粗标题字 + 描边 + 阴影，入场动画选「放大弹入」类；对白同理
6. 每段素材加关键帧缓慢推近

### 做法 2：用本仓库的 Remotion 模板（可复用、改文案就能出新片）
模板已经实现了上面所有包装效果，只需要放素材、填文案：

1. 素材放进 `public/clips/`，文件名对应 `src/huiyi/config.ts` 里的 `clip`（没有的会显示占位画面）
2. BGM 放到 `public/music/bgm.mp3`，在 `config.ts` 里填 `bpm` 和 `offsetSec`（第一个重拍的时间）
3. 改 `SCENES` 里的标题、英文、对白和位置（`x` / `y` 是画面百分比，`beat` 是第几拍出现）
4. `npm run dev` 实时预览，`npm run render` 出片

节奏不规整的歌，可以直接在 `CUTS_SEC` 里手填每个切点的秒数。

可调参数：

| 参数 | 位置 | 作用 |
|---|---|---|
| `TRANSITION_HALF` | config.ts | 转场半程帧数，越小越「砸」，越大越柔 |
| `BEAT_PUNCH` | config.ts | 每拍顿一下的力度，0 关闭 |
| `speed` | 每个场景 | 素材播放速度，把慢的动画压进节拍里 |
| `clipStartSec` | 每个场景 | 从素材第几秒开始用 |
