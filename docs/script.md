## 参考文案拆解

**保留的核心**（它火的原因）
1. 开头用具体行为戳人：几个小时没回、刷手机、语气淡一点就失眠
2. 一句反转：不是你太爱对方
3. 给一个能解释一切的概念：共生，并讲清它从哪来，也就是没完成的分离
4. 能对号入座：对方要空间，你觉得被抛弃；对方有边界，你读成冷漠
5. 两个具体代价
6. 落在一个当下就能做的动作：停下来，问自己一句话

**改掉的地方**

| 原文 | 问题 | 改法 |
|---|---|---|
| 刚出生分不清自己和母亲（说得像定论） | 这是 Mahler 的精神分析理论。后来 Stern 1985 等婴儿研究认为，婴儿很早就能区分自己和他人 | 注释标「一种经典理论」，字幕不说"科学证明" |
| 父母情绪不稳、过度入侵，导致没完成分离 | 单一归因，有原生家庭决定论的味道，平台也敏感 | 注释标「可能原因之一」，不点名父母的错 |
| 离了对方活不下去 | 自伤相关表述，有平台风险 | 改成「离了你我不行」 |
| 吸你血的人、渣 | 攻击性标签 | 删掉 |
| 我跟学员讲 | 带货、卖课的引子 | 删掉 |
| 他、她混用 | 性别化 | 统一用「TA」 |
| 全文约 1500 字口播 | 没有口播，字幕要能读完 | 压到约 400 字，每屏一句，不超过 14 字一行 |

**加进来的创新**
1. **把边界画出来**：圆的轮廓线就是心理边界。没完成分离，线是断的；结尾线自己长出来。抽象词变成一个看得见的过程
2. **「妈妈不再秒回」**：婴儿学会分离和成年人等消息，是同一个画面、同一个动作，也就是呼唤之后回应来迟了。观众会自己把两段接上
3. **反常识的反转**：温尼科特说，独处的能力是在有人陪着的时候学会的。这解决了原文的一个问题：只给原因，不给希望，听起来像宿命
4. **金句压成一对**：「共生是 离了你我不行」「爱是 我可以 但我选你」
5. **结尾回扣**：同样是三个小时没回，这次计数停在 0，圆的线是完整的

- 白圆：你，象牙白 #E8E3D9
- 金圆：TA 或妈妈，金 #DDBD74
- 圆的轮廓线 = 心理边界：实线表示完整，虚线或断线表示没长好，朱红颤动表示焦虑
