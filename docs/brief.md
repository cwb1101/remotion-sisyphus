# 全片设定（每一步都要遵守）

- 主题：总观效应（Overview Effect）
- 时长：约 150 秒（120–150 秒）
- 规格：1920×1080 横屏，30fps；无口播，屏幕字幕就是全部文字
- 画面：全部用 Remotion 代码画（形状、光、线条、粒子、文字），不用实拍、图库、AI 生成图
- 字体：思源黑体 / 思源宋体（Noto Sans SC / Noto Serif SC）；主字幕 ≥ 64px，放画面中部
- 音乐：`assets/music/bgm.mp3`（用户提供）；换屏、动作、音效都卡这首曲子的拍点（见 `assets/music/bgm.analysis.json`）
- 音效：全部用代码合成 wav，不用音效素材
- 水印：右上角固定「肆号静匣Logos」，细空心方框包住，字号约 22px，线宽 1px，透明度约 35%；
  不跟镜头运动或缩放，全程固定；字幕和其它动画文字不进入该区域
- 安全区：底部 10%（y > 972）留给抖音界面，不放主字幕

## 风格规矩
1. 先演后讲：开头先演一个具体的小东西或反常识现象，片名卡不放开头
2. 一个物件贯穿全片：新概念尽量让这个物件变形来表达，不另起新图形
3. 字幕说到什么，画面就演什么：说到的数字和过程，画面上都要真的出现
4. 叙事：钩子 → 实证 → 命名概念 → 落到观众自己 → 讲机制 → 金句；先现象后概念
5. 结尾回到开头：开头画面再出现一次，但意思已经变了
6. 层级：图形 > 主字幕 > 附着标签 > 注释；每屏只讲一个观点
7. 有静有动：读字时主体可停，但画面要呼吸（漂移、光、粒子），镜头完全静止 ≤ 3 秒；
   全片只有 3–5 处大动作（字砸下、全屏变化、重音效），留给主题词和关键句，且都落在音乐重拍上
8. 不用：霓虹色、玻璃拟态、HUD 网格、故障闪烁、emoji
9. 事实要有出处；推测标「示意」「据说」；片尾列出处

- 鎏金暗场：暖近黑底，象牙白 #E8E3D9，金 #DDBD74，朱红 #D9583C；失焦尘埃，四角压暗；粗宋逐字由虚变实，重点词染金
- 夜曲：蓝黑夜空 + 细小星点，白 #F8F9F8，金 #F8D893，冰蓝 #64E3F6，玫红 #E84B75；细宋，大字距，整行淡入
- 寓言：每场一幅扁平代码插画，暖白 #FFFAEB，金 #EEC672，关键词红 #FC593F
